# 아파트 시스템 지도

`index.html` 한 장과 `data.json` 한 장으로 돌아간다. 외부 라이브러리 없음 (서체만 Google Fonts).

- `data.json`을 고치면 지도가 바뀐다. 노드의 `urls` 배열에 원문 링크를 넣으면 패널에 뜬다.
- `index.html` 안에도 같은 데이터가 들어 있다(오프라인 대비). `data.json`이 있으면 그쪽을 먼저 읽는다.
- GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).
- 특정 노드 링크: `…/index.html#SHAREFEE` 처럼 노드 ID를 붙인다.
